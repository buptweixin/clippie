# Demo storyboard (< 3 minutes, real machine, no mockups)

1. **0:00–0:25 — The resurrection.** Blank Word doc. The paperclip slides in:
   "It looks like you're trying to write a document…" — then, pointedly,
   says nothing else. Restraint is the first feature.
2. **0:25–1:20 — The stuck moment.** Writing a paper's Related Work →
   Method transition. The same sentence gets rewritten three times; the
   reference PDF gets alt-tabbed to four times. Clippie offers a finished
   two-sentence bridge with citation placeholders: [Insert] [Another]
   [Dismiss]. One click — it's in the document, at the cursor.
3. **1:20–2:00 — The loop closing.** The inserted text is kept and written
   past (positive feedback, shown in the debug overlay). Then a bad
   suggestion gets dismissed three times — Clippie goes silent for
   30 minutes and *says* it will. Feedback is visible, not magic.
4. **2:00–2:30 — The honest degradation.** An elevated/admin window where
   only paste works: the bubble says "Inserted by paste — this window
   doesn't expose a writable accessibility tree." No pretending.
5. **2:30–2:55 — Classic mode + close.** Classic mode ON: full 1997 eager
   Clippy for ten seconds of comedy. OFF. Repo link, Kiro specs/steering
   on screen, one line: "Dead software, back with a brain — and with
   manners."
