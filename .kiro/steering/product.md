# Steering — product rules (always in context)

- **Restraint is the brand.** When confidence is low, Clippie does nothing.
  A missed opportunity is cheaper than one bad interruption.
- **Artifacts, not advice.** Never surface "you could try…". Surface a
  finished, insertable artifact, or stay silent.
- **Three actions max** on any bubble: Insert / Another version / Dismiss.
- **Dismissals are data.** 3 dismissals → 30 minutes of silence and a raised
  threshold for that stuck type in that app.
- **Classic mode is a joke mode**, opt-in only, never the default behaviour
  and never in the core demo flow.
- **Honesty about capability.** If an execution layer degraded (e.g. only
  clipboard paste is possible in this window), the bubble says so.
